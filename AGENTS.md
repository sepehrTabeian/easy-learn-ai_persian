# Agent instructions

This fork is being translated from Chinese to Persian (RTL) on branch `persian`.

- Before starting, read `docs/translation/TRANSLATION_STATUS.md` (status, pipeline, pitfalls, glossary).
- At the end of every task, update `docs/translation/TRANSLATION_STATUS.md` (status table, next step, changelog, new pitfalls) and move finished `tr_*.tsv` files from `docs/translation/work/` to `docs/translation/glossary/`.
- Do not run `npm install` / `pnpm install` without asking the user. Do not open PRs.
