## زنجیرهٔ ابزار و Agentها

### درباره‌ی Cline، LangChain، Notion و Cursor همزمان به سمت «پلتفرم Agent با اجرای طولانی» رفتند

شرکت Cline SDK و CLI خود را بازنویسی و متن‌باز کرد؛ شامل رابط ترمینالی، تیم‌های Agent، کارهای زمان‌بندی‌شده و اتصال‌دهنده‌ها، با هدف تبدیل شدن به زیرساخت قابل‌استفادهٔ مجدد برای Agentهای کدنویس. LangChain در رویداد Interrupt مجموعه‌ای از زیرساخت‌های Agent را عرضه کرد: LangSmith Engine، SmithDB، sandbox، Managed Deep Agents، LLM Gateway و Context Hub. Notion هم API مربوط به Agentهای بیرونی را باز کرد تا Claude، Codex و Cursor مستقیم داخل Notion کار کنند. Cursor محیط کامل توسعهٔ دوردست را برای Agentهای ابری ساخته؛ شامل کلون مخزن، نصب وابستگی، بازگشت به نسخهٔ قبل و کلیدهای جداشده. روند کلی: از «گفت‌وگو» به سمت «وضعیت پایدار و هماهنگی» می‌رویم.

### تجربهٔ کاربری Agent از «جعبهٔ گفت‌وگو» به «کار بلندمدت + وضعیت زنده + هماهنگی» تغییر می‌کند

درباره‌ی Duet Agent چارچوبی بر پایهٔ ماشین حالت پیشنهاد داده که کارهایی چند هفته‌ای را با Agentهای والد و فرزند و حافظه اجرا می‌کند. به‌روزرسانی Agent در LangChain رویدادهای ساختاریافتهٔ جریانی، ذخیرهٔ نقطهٔ بازرسی، مفسر کد و سفارشی‌سازی مدل را اضافه کرده است. Tabracadabra از تکمیل خودکار به دستیار متنی در هر کادر ورودی رسیده و VS Code پنجرهٔ Agents و بازبینی کارهای چند پروژه را اضافه کرده است. نکتهٔ مهم این است که Agent در عمل تولید به وضعیت میانی قابل‌بازپخش و ادغام عمیق در ابزار توسعه نیاز دارد، نه گفت‌وگوی بی‌حافظه.

### درباره‌ی TextGen به برنامهٔ دسکتاپ محلی تبدیل شد؛ گزینه‌ای متن‌باز مثل LM Studio

پروژهٔ قدیمی text-generation-webui به برنامهٔ دسکتاپ TextGen با Electron بازنویسی شد و روی ویندوز، لینوکس و macOS اجرا می‌شود. پشتیبانی از پشته‌های CUDA، Vulkan، CPU، ROCm و Apple Silicon دارد. به‌صورت پیش‌فرض اینترنت را بی‌دلیل استفاده نمی‌کند، کوانتیزاسیون تازهٔ ik_llama.cpp را دارد، جست‌وجوی ddgs، فراخوانی ابزار MCP و API سازگار با OpenAI و Anthropic (از جمله Claude Code) را داراست، و PDF و پاک‌سازی صفحه‌های وب را هم پردازش می‌کند. هدفش جایگزین متن‌باز و خصوصی‌تر LM Studio است.

### جنگ Codex و Claude بر سر یارانه و سهمیه: از کیفیت مدل به بسته‌های هزینه و محیط کار

مدل Claude قیمت‌گذاری را تغییر داده: برای هر مبلغ اشتراک، همان مبلغ کوپن API داده می‌شود که در Agent SDK، claude -p و GitHub Actions قابل استفاده است. این کار عملاً استفادهٔ قبلی از اشتراک برای فراخوانی API در ابزارهایی مثل OpenClaw را محدود کرده و شکایت گستردهٔ توسعه‌دهندگان را در پی داشته است. هم‌زمان Anthropic سهمیهٔ هفتگی Claude Code را دو برابر و بعد ۵۰٪ دیگر بالا برد. OpenAI هم برای شرکت‌هایی که طی ۳۰ روز به Codex می‌آیند، دو ماه استفادهٔ رایگان داده و جزئیات طراحی جعبهٔ شنی Windows را منتشر کرده است. رقابت از کیفیت مدل به «کدام یارانه بیشتر و کدام محیط کار را در اختیار دارد» رسیده است.

### درباره‌ی Perplexity جعبهٔ شنی امن را برای شرکت‌ها برجسته کرد

درباره‌ی Perplexity جزئیات جعبهٔ شنی سخت‌افزاری خود را توضیح داده: جداسازی VPC، توکن‌های کوتاه‌عمر پروکسی، بررسی محتوای خروجی، رمزنگاری و حذف خودکار. به گفتهٔ شرکت، این شرط ورود به بازار پایگاه دانش و پژوهش سازمانی است. روند کلی این است که Agent فقط با «هوشمند بودن» فروخته نمی‌شود، بلکه با محیط اجرای امن درون مرزهای مشخص فروخته می‌شود.

### کد تولیدشده با AI به بدهی فنی تبدیل شده و حالا با AI پاک می‌شود

مهندسی یک مخزن بک‌اند سه‌ماهه را تحویل گرفت که توسط یک «مهندس وایب‌کد» ساخته شده بود: ۳۰۰ هزار خط، لاگ‌های فراوان، handlerهای بی‌استفاده و ده‌ها کلید بی‌مصرف. او با کمک Claude در یک هفته بازنویسی کرد؛ PR نهایی ۳٫۶ میلیون خط حذف و ۱۰ هزار خط اضافه نشان می‌داد. نظرها می‌گویند پاک‌سازی بدهی فنی تولیدشده با AI می‌تواند بازار تازه‌ای باشد.

### دستیار عروسی با AI: مهمان‌ها بیشتر وقت خود را صرف شکستن آن کردند

کسی برای عروسی در موریس یک دستیار AI ساخته که با API اطلاعات عروسی و سفر را از طریق MCP می‌خواند. ۲۹ مهمان ۸۶۷۸ پیام فرستادند و حدود ۲۵٪ آن‌ها تلاش برای جیلبریک یا شوخی بود. این پروژه نشان می‌دهد حتی در محیط کوچک و خصوصی، هر جا ورودی چت باشد کاربران خودبه‌خود آزمایش امنیتی می‌کنند؛ پس باید از اول به لاگ، حریم خصوصی و دفاع در برابر جیلبریک فکر کرد.

## ربات‌های انسان‌نما

### ربات‌های انسان‌نمای Figure هشت ساعت پشت هم بسته‌های پستی را دسته‌بندی کردند

درباره‌ی Figure در یک پخش زنده چند ربات انسان‌نما را نشان داد که با مدل Helix-02 مستقیم از پیکسل‌های دوربین استدلال می‌کنند و در انبار هشت ساعت پشت هم بسته‌ها را جدا می‌کنند؛ هر بسته حدود سه ثانیه و نزدیک سرعت انسان. استنتاج روی خود ربات انجام می‌شود، ربات‌ها با هم هماهنگ می‌شوند، وقتی باتری کم است جای خود را به دیگری می‌دهند و خودشان خطایابی و تعمیر را آغاز می‌کنند. این نمایش طولانی و چندربات و بدون دخالت انسان، از ویدیوهای کوتاه دمو به واقعیت استقرار نزدیک‌تر است.
